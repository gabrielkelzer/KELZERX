# 📌 Sobre o Kelzer-X

Kelzer-X é uma interface desenvolvida em Shell Script para Termux/Linux criada com foco em automação de ferramentas relacionadas ao Metasploit Framework no Android.

O projeto foi desenvolvido por Gabriel Kelzer com o objetivo de facilitar processos que normalmente seriam feitos manualmente no terminal, tornando a utilização do Metasploit mais rápida e organizada dentro do Termux.

Além da automação, o script também possui uma interface visual em ASCII Art inspirada em ambientes cyberpunk e terminais Linux clássicos.

---

# ⚙️ O que o script faz?

O Kelzer-X automatiza processos envolvendo o Metasploit Framework e APKTool dentro do Termux.

Entre suas funcionalidades estão:

- Instalação automática do Metasploit no Termux
- Instalação do APKTool
- Automatização da criação de payloads utilizando o Metasploit
- Interface interativa no terminal
- Organização de comandos em menu visual
- Personalização visual em ASCII Art

O script foi criado para simplificar tarefas que normalmente exigiriam diversos comandos manuais no Linux/Termux.

# 🎯 Objetivo do Projeto

O objetivo do Kelzer-X é demonstrar automação em Shell Script, personalização de interfaces CLI e integração de ferramentas utilizadas em ambientes Linux e Termux.

O projeto também foi desenvolvido como forma de estudo envolvendo:

- Shell Script
- Bash
- Automação no terminal
- Interface visual em ASCII
- Ambientes Linux/Android
